Hybrid Instrument // Help

Image Bay

1. Click + and choose an image.
2. Set alignment (L/C/R) and shape (RECT / ○).
3. Adjust IMG W knob.
4. Place caret → click INSERT. Image appears live in the text.

Cadence Panel

Shows sentence-length rhythm (Gary Provost style), word counts, average length, estimated reading time, and repeated-word “echo” radar. Click an echo badge to jump/search.

Lexicon

Type a word or highlight text in the editor, then FIND. Pulls definitions, related terms and rhymes (Free Dictionary / Datamuse style endpoints when available).

Shortcuts

  • ? or Ctrl+/ — Help
  • Esc — Close help / exit Zen
  • Ctrl+Z — Undo
  • Ctrl+S — Save sheet
  • Ctrl+Shift+Z — Zen mode
  • Focus knob → ↑↓ or []
