IBM SYSTEM/370 CONSOLE // MANUAL

Direct Optics (Images)

1. Paste (`Ctrl`+`V`) or drag-and-drop any image directly onto the CRT console editor, or click ◰ INSERT IMAGE on the deck.
2. Click any inserted image to bring up the Floating Cathode HUD.
3. Directly toggle alignment (L / C / R), aperture shape (RECT / ○), scale width with - / +, or purge with ✕.

Cadence Rhythm Analysis

Calculates Gary Provost sentence dynamics, lexical diversity percentage, and automated repetition detection. Clicking on any repetition badge mounts the query directly into the Lexicon.

Multiplex Video Channel

Displays a muted live cathode background under the phosphor buffer. Dial VID G regulates transparency gain.

  • ? or Ctrl+/ — Console Help
  • Esc — Dismiss Overlay / Close Image HUD / Exit Zen
  • Ctrl+Z — Undo
  • Ctrl+S — Sector Checkpoint
  • Ctrl+Shift+Z — Cathode Zen Mode
