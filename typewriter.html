Image Bay Workflow

1. Click + and choose an image.

2. Set alignment (L / C / R) and shape (RECT / CIRCLE).

3. Adjust IMG WIDTH with the knob.

4. Place the caret where you want the image, then click INSERT.

The image appears immediately in the writing surface. It is stored as a marker so PDF export still works correctly.

Keyboard Shortcuts

  • ? or Ctrl+/ — Open this help
  • Esc — Close help / exit Zen mode
  • Ctrl+Z — Undo
  • Ctrl+S — Force save current sheet
  • Ctrl+Shift+Z — Toggle Zen mode
  • Focus a knob, then use ↑ ↓ or [ ] to adjust

Other Notes

  • Marquee pauses while you hover it.
  • Sheets are saved locally in your browser.
  • PDF respects current font, size, and line pitch.
  • Custom YouTube IDs are remembered.
