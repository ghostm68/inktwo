How-to · Photo size & detection

Detection is now scale-aware. The engine measures typical letter height and converts noise/split thresholds relative to it, so close-up and farther photos behave more consistently.

Best results:

  • Crop tightly around one clean line (or a short paragraph).
  • Aim for letters roughly 30–80 px tall after load (status line shows the estimate).
  • Prefer Adaptive Threshold + Auto-Split for handwriting.
  • Use AI Read Line (TrOCR) on a tight crop to auto-fill the Target Character Order from the handwriting (on-device model, ~64 MB first load).
  • If letters stay stuck, open a glyph and use the Split tool.
  • Raise Speckle Sensitivity if you see dust/noise; lower it if thin strokes disappear.

Very tiny letters (<22 px) or extremely large ones may still need a tighter crop or a closer photo for best auto-split accuracy.
